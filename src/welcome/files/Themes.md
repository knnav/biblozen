# Themes

Biblozen separates **color** from **typography**.

## Color themes

Press <kbd>t</kbd> (or <kbd>Mod</kbd>+<kbd>K</kbd> <kbd>Mod</kbd>+<kbd>T</kbd>) to open the theme picker. Arrow keys preview each theme across the whole window; <kbd>Enter</kbd> keeps it and <kbd>Esc</kbd> puts the old one back.

By default Biblozen follows your system's light or dark appearance, with one theme for each.

### Your own themes

Drop a VS Code theme (`.json`) or a Biblozen theme into the `themes` folder inside the data folder. It shows up in the picker straight away — no restart.

## Reading styles

Reading styles change only the preview's typography:

- **GitHub** — familiar sans-serif, GitHub's spacing
- **Book** — a serif at a book-like measure with generous leading
- **Academic** — serif, numbered headings, prominent footnotes
- **Compact** — dense, for reference docs
- **Mono** — monospace everything

Pick one from the status bar or the command palette.
