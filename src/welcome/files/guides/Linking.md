# Linking notes

Link to any note by name with double brackets: [[Welcome]], [[Rendering#Math|the math section]], or a path like [[guides/Linking]].

- Names match case-insensitively, with or without `.md`.
- When two notes share a name, the one with the shortest path wins.
- Links to notes that don't exist yet look like this: [[A note to write later]]. Click one to create the note.

## Backlinks

Press <kbd>b</kbd> to see which notes link here. This page is linked from [[Welcome]].
