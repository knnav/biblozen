# Editing

Press <kbd>e</kbd> or <kbd>Mod</kbd>+<kbd>E</kbd> to edit. By default the editor and preview sit side by side; <kbd>Mod</kbd>+<kbd>\</kbd> hides the preview.

- <kbd>Mod</kbd>+<kbd>B</kbd> bold, <kbd>Mod</kbd>+<kbd>I</kbd> italic, <kbd>Mod</kbd>+<kbd>K</kbd> link, <kbd>Mod</kbd>+<kbd>`</kbd> inline code
- Lists continue when you press <kbd>Enter</kbd>; <kbd>Tab</kbd> and <kbd>Shift</kbd>+<kbd>Tab</kbd> indent
- <kbd>Mod</kbd>+<kbd>F</kbd> finds, <kbd>Mod</kbd>+<kbd>H</kbd> replaces
- Type `[[` to link to another note

## Saving

<kbd>Mod</kbd>+<kbd>S</kbd> saves. Files are written atomically and keep their original line endings. If a file changes on disk while you have unsaved edits, a banner lets you choose which version to keep.

## Images

Paste or drop an image into the editor. It's saved to an `assets/` folder next to the document and linked for you.
