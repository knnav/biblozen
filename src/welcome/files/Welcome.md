# Welcome to Biblozen

Biblozen is a quiet place to **read** Markdown. Open any folder of notes, docs or a project's `docs/` directory, and it lands in read mode, set in comfortable type. When you want to change something, editing is one keystroke away.

> [!TIP]
> Press <kbd>e</kbd> to edit this page and <kbd>Mod</kbd>+<kbd>E</kbd> to go back to reading. Nothing is saved until you press <kbd>Mod</kbd>+<kbd>S</kbd>.

## Find your way around

| To… | Press |
| --- | --- |
| Run any command | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> |
| Jump to a file | <kbd>Mod</kbd>+<kbd>P</kbd> |
| Search every file | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> |
| Show the outline | <kbd>o</kbd> |
| Change the theme | <kbd>t</kbd> |
| Hide the sidebar | <kbd>Mod</kbd>+<kbd>B</kbd> |
| Focus mode | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> |

`Mod` is <kbd>⌘</kbd> on macOS and <kbd>Ctrl</kbd> on Windows.

## Where things live

Biblozen never adds hidden files to your folders. Settings, themes and window state live in one data folder — on Windows next to `Biblozen.exe` in `data\`, on macOS in `~/Library/Application Support/Biblozen/`. This Welcome folder is a copy in that data folder, so feel free to scribble on it.
