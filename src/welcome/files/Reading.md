# Reading

Biblozen is built for reading with the keyboard. When the document has focus, single keys work:

| Key | Action |
| --- | --- |
| <kbd>j</kbd> / <kbd>k</kbd> | Scroll a line down / up |
| <kbd>d</kbd> / <kbd>u</kbd> | Half a page down / up |
| <kbd>Space</kbd> / <kbd>Shift</kbd>+<kbd>Space</kbd> | A page down / up |
| <kbd>g</kbd> <kbd>g</kbd> / <kbd>G</kbd> | Top / bottom |
| <kbd>/</kbd> | Find in this document |
| <kbd>n</kbd> / <kbd>N</kbd> | Next / previous match |
| <kbd>o</kbd> | Outline |
| <kbd>b</kbd> | Backlinks |
| <kbd>[</kbd> / <kbd>]</kbd> | Back / forward |
| <kbd>t</kbd> | Theme picker |
| <kbd>e</kbd> | Edit |

## Outline

Press <kbd>o</kbd> for the outline. The current section is highlighted as you scroll; click a heading to jump.

## History

Every jump — a link, a search result, the outline — is remembered. Go back with <kbd>[</kbd> or <kbd>Mod</kbd>+<kbd>[</kbd>, forward with <kbd>]</kbd>.

## Picking up where you left off

Each file remembers where you stopped reading. Open it tomorrow and you're back at the same paragraph.

## Width and zoom

Change the reading width in Settings (<kbd>Mod</kbd>+<kbd>,</kbd>). Zoom the preview with <kbd>Mod</kbd>+<kbd>=</kbd> and <kbd>Mod</kbd>+<kbd>-</kbd>; <kbd>Mod</kbd>+<kbd>0</kbd> resets.
