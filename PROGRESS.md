### 2. Deviations from SPEC.md

None from the §2 decisions log. Every interpretation and judgment call is in [DECISIONS.md](DECISIONS.md). The ones a reviewer should know about:

- DOMPurify runs on every block that contains raw HTML, not on the whole document string. markdown-it escapes everything else. This took 1 MB documents from ~2 s to under 300 ms. The CSP blocks inline scripts as a second layer.
- Extra Tauri commands beyond §4.1: file operations, routing/session, export, print and the env-gated self-test. All are scope-checked.
- Session restore is owned by Rust (`session.json`).
- Legibility rules are stricter than "body text ≥ 4.5:1": all small text meets WCAG AA.

## Quality gate commands

```
npm run lint && npm run typecheck && npm run format:check && npm test && npm run e2e
(cd src-tauri && cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test)
npm run tauri build
npx tauri build --runner cargo-xwin --target x86_64-pc-windows-msvc --no-bundle   # Windows cross-check
scripts/smoke.sh                 # real-backend self-test against the Linux release binary
scripts/smoke-windows.sh         # (WSL) same self-test on the Windows host
scripts/multiwindow.sh           # real CLI args, single-instance forwarding, routing, session restore (Linux)
scripts/multiwindow-windows.sh   # (WSL) the same on the Windows host
```

The self-test (`src/smoke.ts`, env `BIBLOZEN_SMOKE_DIR`) drives the platform layer through real Tauri IPC — capabilities, scopes, atomic writes, CRLF, rename, duplicate, watcher, trash, out-of-scope rejection — and writes a JSON report.
